# Refleksi Praktikum DevOps - Pertemuan 01

Melalui rangkaian praktikum ini, saya berekspektasi untuk dapat menjembatani kesenjangan antara teori rekayasa perangkat lunak dengan realitas operasional di industri. Secara spesifik, saya menargetkan penguasaan fundamental teknis terhadap *tools* esensial seperti Git untuk kontrol versi dan Docker untuk kontainerisasi. 

Lebih jauh, saya berharap praktikum ini membekali saya dengan kemampuan analitis dan praktis untuk membangun arsitektur *pipeline* otomatisasi. Tujuannya adalah agar saya tidak hanya mampu menulis kode, tetapi juga memahami proses orkestrasi, pengujian, dan distribusi perangkat lunak secara efisien sesuai dengan standar ekosistem *cloud-native* terkini.
